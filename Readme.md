# Deep Learning Basics with PyTorch

## Overview
This project provides an introduction to **Deep Learning using PyTorch**. It covers fundamental concepts, including **tensors, autograd, neural networks, and model training**, to help beginners get started with deep learning using PyTorch.

## Prerequisites
Before you begin, ensure you have the following installed:
- **Python 3.x**
- **PyTorch**
- **NumPy**
- **Matplotlib** (for visualization)

Install dependencies using:
```bash
pip install torch torchvision numpy matplotlib
```
